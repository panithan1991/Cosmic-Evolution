# 🌌 Cosmic Evolution

[▶️ เล่นเกม](https://panithan1991.github.io/Cosmic-Evolution/) · [🎨 ดูภาพดาวและกาแล็กซี](https://panithan1991.github.io/Cosmic-Evolution/art-gallery.html)

เกมเอาตัวรอดบนเว็บ สำรวจ **สเกลจักรวาล** จากดาวเคราะห์ ดาวฤกษ์ และซากดาว ไปถึงกาแล็กซีและใยจักรวาล ภาพดาวและกาแล็กซีวาดด้วย Canvas โดยไม่ต้องโหลดรูปจากที่อื่น

## เล่นอย่างไร

| สิ่งที่เห็น | ความหมาย | ทำอะไร |
|---|---|---|
| ◆ เพชรสีเขียว | ฝุ่นและแก๊ส | เคลื่อนตัวเข้าไปเก็บเพื่อเพิ่มคะแนน Mass |
| + วงเขียวรอบวัตถุ | ดูดซับได้ในสเกลปัจจุบัน | แตะเพื่อรับ Mass เพิ่ม |
| ! วงแดงรอบวัตถุ | ยังเป็นภัย | หลบหรือกดค้างเพื่อผลักออก |
| เพชรแดง | กระสุน/พลังของภัย | หลบ |

ใช้เมาส์หรือสัมผัสหน้าจอเพื่อเคลื่อนที่ กดเมาส์ค้างหรือกด Space เพื่อผลักวัตถุรอบตัว การผลักใช้พลังงานและหยุดเก็บฝุ่นชั่วคราว เมื่อ Mass ถึงเป้าหมายจะปลดล็อกสเกลใหม่ เกมดำเนินต่อได้แม้ปลดล็อกสเกลสุดท้าย โดย **Gravity Well** ยังคงเป็นภัยให้หลบ คะแนนสูงสุดเก็บในเบราว์เซอร์เครื่องนั้น

## วิทยาศาสตร์ในเกม

ลำดับบนจอคือ **เส้นทางปลดล็อกเพื่อการเล่น** ไม่ใช่วงจรชีวิตของวัตถุเดียว คะแนน Mass เป็นหน่วยสมมติ ไม่ใช่มวลจริง ดาวเคราะห์ไม่กลายเป็นดาวฤกษ์ ดาวนิวตรอนและหลุมดำเป็นซากดาวฤกษ์มวลสูงคนละทางเลือก หลุมดำไม่กลายเป็นกาแล็กซี ส่วนกาแล็กซีเป็นระบบของดาว แก๊ส ฝุ่น และสสารมืดที่แรงโน้มถ่วงยึดไว้ รูปทรงเกลียวและเกลียวมีคานเป็นชนิดของกาแล็กซี ไม่ใช่ขั้นอายุถัดกัน

ข้อมูลประกอบ: [NASA: Star Lifecycle](https://science.nasa.gov/mission/webb/star-lifecycle/), [NASA: Hubble Galaxies](https://science.nasa.gov/mission/hubble/science/universe-uncovered/hubble-galaxies/), [NASA: Types of Galaxies](https://science.nasa.gov/universe/galaxies/types/), [NASA: Large Scale Structures](https://science.nasa.gov/universe/galaxies/large-scale-structures/), [NASA: Black Holes](https://science.nasa.gov/mission/hubble/science/universe-uncovered/hubble-black-holes/).

## การแก้ไขสำคัญ

- แยกสิ่งที่เก็บได้ ภัย และวัตถุที่เพิ่งดูดซับได้ด้วย **รูปทรง สี และสัญลักษณ์** ไม่พึ่งสีอย่างเดียว
- แก้ระเบิดที่เคยทำอันตรายแม้ปลดล็อกให้ดูดซับได้แล้ว และหยุดการยิงของภัยเมื่อกลายเป็นวัตถุที่ดูดซับได้
- ตรวจชนจากตำแหน่งหลังเคลื่อนที่ ลดการชนก่อน/หลังภาพจริง
- ปรับจำนวนฝุ่นตามพื้นที่หน้าจอ ลดความรกและลดภาระวาดภาพ โดยยังคงการสะสม Mass ต่อเนื่อง
- จำกัดระยะแรงดึงดูดให้สมดุลกับขนาดจอ และให้ภัยระดับสูงตามทันผู้เล่นที่ปลดล็อกเร็ว ลดช่วงที่เกมง่ายเกินไป
- เพิ่มคำอธิบายวิทยาศาสตร์ตามสเกล และเปลี่ยนช่วงกาแล็กซีตอนปลายให้เป็นคู่/กลุ่มกาแล็กซีแทนการเรียงรูปทรงผิดความหมาย
