# 🌌 Cosmic Evolution

เกมจำลองการวิวัฒนาการของวัตถุในจักรวาลแบบ Interactive เริ่มจากวัตถุขนาดเล็ก สะสมมวล หลบหลีกหรือกำจัดศัตรู และวิวัฒนาการไปสู่วัตถุจักรวาลที่ทรงพลังยิ่งขึ้น

## Gameplay

- สะสม **Mass** เพื่อวิวัฒนาการ
- ผ่านลำดับวิวัฒนาการของวัตถุท้องฟ้าตามแนวคิดทางดาราศาสตร์
- เผชิญ **Cosmic Threats** ที่แตกต่างกันในแต่ละช่วง
- ดูเส้นทางวิวัฒนาการและตำแหน่งปัจจุบันได้แบบ Real-time
- เป้าหมายคือพัฒนาไปสู่โครงสร้างระดับ **Galaxy**

## Features

- 🌟 Cosmic Evolution System
- 👾 Dynamic Enemies & Cosmic Threats
- 🧬 Evolution Progress Timeline
- 🌌 Realistic-inspired Galaxy Visuals
- 📈 Mass-based Progression
- 🎮 เล่นง่ายบน Web Browser
